# HackerRank Practice

Repositorio de práctica para resolver ejercicios de HackerRank con foco en análisis algorítmico antes de programar.

## Método de trabajo

Cada ejercicio se resuelve siguiendo este orden:

1. Comprender el enunciado.
2. Definir entrada y salida.
3. Identificar variables y restricciones.
4. Escribir la solución en lenguaje natural.
5. Dibujar el diagrama de flujo.
6. Hacer una prueba de escritorio.
7. Escribir pseudocódigo.
8. Implementar la solución.
9. Probar casos normales y casos límite.

## Estructura

```text
algorithms/
  warmup/
  implementation/
  strings/
  sorting/
  search/
data-structures/
notes/
```

Cada ejercicio tendrá su propia carpeta. Ejemplo:

```text
algorithms/warmup/simple-array-sum/
  README.md
  diagram.png
  solution.java
```

El `README.md` de cada ejercicio contiene el análisis, la prueba de escritorio y el pseudocódigo. El archivo `diagram.png` guarda el diagrama hecho a mano o digitalizado, y `solution.*` contiene la implementación final.

## Regla principal

No empezar a programar hasta poder explicar claramente cómo resolver el problema sin depender de la sintaxis de un lenguaje.
