# HackerRank Practice

A simple repository for my HackerRank exercises and algorithm practice.

The goal is to keep solutions organized without forcing a fixed structure for every challenge. Depending on the exercise, I may include code, notes, pseudocode, diagrams, or other material that helps document the reasoning process.

## Structure

```text
exercises/
└── algorithms/
```

For now, the repository is focused only on algorithm exercises. New categories can be added later if needed.
